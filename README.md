# DIO - Trilha .NET - Fundamentos

www.dio.me

## Desafio de projeto

Este é um desafio de projeto proposto pelos educadores da Dio com o objetivo de usar os conhecimentos adquiridos no módulo de fundamentos, da trilha .NET da DIO.

## Sobre o projeto

Trate-se de um sistema para estacionamento, que será usado para gerenciar os veículos estacionados e realizar suas operações, como por exemplo adicionar um veículo, remover um veículo (e exibir o valor cobrado durante o período) e listar os veículos.

Dentre os conhecimentos obtidos estão:

- Conceitos básicos da linguagem C#
- Fundamentos de projetos no .NET
- Comandos Git e GitHub

## Solução

Neste desafio o objetivo era implementar trechos de códigos na classe Estacionamento para as funções: Adicionar Veículos, Remover Veículos e Listar Veículos funcionasse corretamente.
